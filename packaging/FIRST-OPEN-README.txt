X3-UI 离线安装器 1.1.4 - 首次打开说明

适用设备：Apple 芯片 Mac，macOS 13 或更高版本。不支持 Intel Mac。

1. 解压 ZIP，将“X3-UI Offline Installer.app”放到“应用程序”文件夹，双击打开。
2. 这个版本没有 Apple Developer ID 签名及公证。若 macOS 提示无法验证开发者，
   先尝试打开一次，再进入“系统设置 > 隐私与安全性”，找到该应用并点“仍要打开”，
   在系统弹窗中确认。不要关闭整个系统的 Gatekeeper。
3. 浏览器会打开本机 127.0.0.1 的页面（端口 4179 至 4190 中的一个）。
   应用已内置 Node.js、3X-UI/Xray 安装文件和客户端安装文件；Mac 不需要另装 Node.js。
4. 输入目标 Linux VPS 的公网 IP、SSH 端口、用户名和密码后，安装器才会通过 SSH
   上传文件并安装。目标 VPS 必须可从这台 Mac 连接；“离线”不代表无需网络。
5. 可选 SSH 安全设置：自行填写新用户名和密码，勾选 sudo -i、禁用 root SSH。
   禁用 root 前会验证新用户登录和 sudo；失败时保留或恢复 root SSH。
6. “移除 X3-UI”仅处理本安装器管理的实例；先在目标机备份，确认后才移除。
   SSH 用户、sudo 和 root 登录设置不会随面板删除。

若出现“应用已损坏”或“会损害电脑”等警告，不要强行绕过。先核对 ZIP 的 SHA-256
校验值，重新取得可信的安装包。

本包未经 Apple 公证，不能保证下载到另一台 Mac 后首次双击没有安全提示。
