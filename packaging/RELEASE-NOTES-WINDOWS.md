Windows x64 offline installer with the same pinned 3X-UI 3.9.0 and Xray 26.3.27 server payloads as the macOS edition. The ZIP includes its own Node.js runtime, Windows Xray probe, all 14 client installers, and the illustrated guide. No runtime download is needed on the Windows PC or the target Linux VPS.

Version 1.4.0 adds a separately named LXD container installation option, so an existing X3-UI on the Linux host is not overwritten. The VPS must have initialized LXD storage and networking, and its firewall/security group must permit the selected panel and node ports. The installer waits for the new container's network before installing its dependencies; only installer-managed containers may be recovered or removed by this mode. Host SSH hardening is not performed in container mode.

Download the ZIP and its `.sha256` file, verify the hash, fully extract the ZIP, and run `Start-X3UI.cmd`. The page binds to `127.0.0.1` only. Supported host: Windows 10/11 x64. This package has no publisher code-signing certificate, so Windows may show a security prompt; do not disable Defender or SmartScreen globally.

The GitHub Actions Windows runner checks the extracted bundle, embedded Node.js and Xray executables, launcher, API host restriction, and local client download. It also installs a fresh isolated container on the designated test VPS and requires an HTTP 200 response through the generated node before this release is published. That runner's network path does not prove reachability from the user's own network or Shadowrocket.
