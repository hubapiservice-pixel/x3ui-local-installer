禁用 root 前验证新账号和 sudo；后续异常会尝试恢复，并保留自动回滚保护。

安全与版本说明

首次安装使用 root。启用管理员并禁用 root 后，可用新用户和 sudo -i 找回结果。SSH 密码只用于当前任务，不写入磁盘、浏览器存储或日志。

移除仅针对本安装器管理的面板，先在目标机建立受限备份；不会删除 SSH 用户、sudo 权限或修改 root 登录设置。

Xray 26.3.27 是兼容旧客户端的版本，不含较新内核的后续修复；已有安装不会被自动降级。

使用方法

        
选择客户端查看图文步骤。图片里的红色编号标明实际可见的操作位置，右侧编号说明具体动作；未出现在截图中的后续步骤会明确说明。iOS 商店版尚无同版本实拍，使用标明“流程示意”的操作卡。

        

          

            v2rayNWindows / macOS · 7.25.6
            

              
    
                
  1. 在安装回执点击“复制节点链接”。
    2. 
                
  2. 打开 v2rayN，在“配置项”菜单选择“从剪贴板导入分享链接”。
    3. 
                
  3. 选中导入的节点，测试延迟，再按需开启系统代理或 TUN。
    4. 
              

              
            

          

          

            v2rayNGAndroid · 2.2.6
            

              
    
                
  1. 把安装回执中的节点链接安全地传到安卓手机，并在手机上复制。
    2. 
                
  2. 打开 v2rayNG，点击右上角“+”，选择“Import from Clipboard”（从剪贴板导入）。
    3. 
                
  3. 选中新节点，点击右下角连接按钮，并允许系统 VPN 授权。
    4. 
              

              
            

          

          

            Clash Verge RevWindows / macOS · 2.5.8
            

              
    
                
  1. 先在安装回执点击“下载 Clash 配置”，保存 YAML 文件。
    2. 
                
  2. 打开“订阅”→“新建”，把“类型”改为“本地”，输入名称，点击“选择文件”选中该 YAML，再保存。
    3. 
                
  3. 启用新配置，在“代理”中选择节点；需要全设备代理时再开启“系统代理”或 TUN。
    4. 
              

              
            

          

          

            Clash Meta for AndroidAndroid · 2.11.35
            

              
    
                
  1. 在安装回执下载 Clash YAML 文件，安全地传到安卓手机。
    2. 
                
  2. 打开“Profile”→ 右上角“+”→“File / Import from File”，选择该 YAML。
    3. 
                
  3. 返回首页选中 Profile，点击“Tap to start”并允许 VPN；在代理组中选择节点。
    4. 
              

              

                
                
              

            

          

          

            ShadowrocketmacOS · 2.2.92
            

              
    
                
  1. 在 Mac 上复制安装回执的 VLESS 节点链接。
    2. 
                
  2. 打开 Shadowrocket，点击右上角“+”；在“添加节点”页把“类型”从 Subscribe 改为 VLESS。
    3. 
                
  3. 核对端口、REALITY 的 SNI、公钥和短 ID，再保存、选中节点并测试连接。
    4. 
              

              
            

          

          

            ShadowrocketiOS · App Store 2.2.92
            

              
    
                
  1. 把安装回执的完整 VLESS 链接安全地传到 iPhone，并在手机上复制。
    2. 
                
  2. 打开 Shadowrocket，使用添加或导入入口粘贴链接；核对 VLESS、TCP 与 REALITY 参数。
    3. 
                
  3. 选中节点，开启连接并允许 iOS 的 VPN 配置请求。
    4. 
              

              
            

          

          

            HiddifyiOS · App Store 4.0
            

              
    
                
  1. 把安装回执的 VLESS 链接安全地传到 iPhone，并在手机上复制。
    2. 
                
  2. 在 Hiddify 的添加配置入口选择从剪贴板导入，并检查导入的节点信息。
    3. 
                
  3. 选择该配置，点击连接并允许 iOS 的 VPN 配置请求。
    4. 
              

              
            

          

        

        
节点导入成功不代表线路可达。若仅这一条超时，请先停止其他全局代理再测，或对比同一设备的物理网络与中转路径。
